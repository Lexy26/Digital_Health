# Parallel Computing for Tumor-Immune System Simulation

A C++ project exploring a tumor-immune system simulation and comparing different parallel computing approaches using **OpenMP** and **`std::thread`**.

The project includes a sequential version and parallel versions with static, dynamic, and pipeline-based execution.

### How to run
```bash
bash benchmark.sh
```
runs the performance tests and saves the results in the `results/` folder (it also runs `make` automatically).
