# Hospitalized Patient and ECG Data Analysis

This project explore clinical records and 12-lead ECG signals from hospitalized patients.

The project covers data exploration, preprocessing, clustering, and classification using both tabular data and ECG time series.

### Project structure
- **Data-Understanding/** — exploratory analysis of patient, triage, vital-sign, wellness, and ECG data.
- **Data-Preparation/** — data cleaning, feature engineering, and ECG signal preprocessing.
- **Clustering/** — K-means, DBSCAN, and hierarchical clustering on tabular and ECG-derived features.
- **Classification/** — classification experiments using clinical features and ECG features, including motif and shapelet analysis.
