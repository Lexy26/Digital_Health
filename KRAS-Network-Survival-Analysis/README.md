# KRAS-Centered Cancer Network and Survival Analysis

The notebooks are numbered according to their respective stages in the pipeline.

### 1. Data Filtering
Prepare the raw data and generate filtered datasets for lung and pancreatic cancer.

### 2. Co-occurrence Analysis
Generate gene co-occurrence tables used to construct the networks.

### 3. Network Analysis
Construct co-occurrence networks and perform:
- Mutational hub identification;
- KRAS role analysis;
- Clustering;
- Enrichment analysis.

### 4. Survival Analysis
Compare patients based on survival outcomes and assess whether specific Leiden clusters are associated with differences in prognosis.

The lung cancer notebook also includes additional analyses not discussed in the report.

### 5. Clinical-to-Network Analysis
Compare different patient groups (e.g., smoking status, age, etc.) and identify the most relevant genes within the network.

Additional analyses not discussed in the report are included at the end of these notebooks.
